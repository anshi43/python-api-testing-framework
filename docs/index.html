QA AUTOMATION PORTFOLIO PROJECT

Python API Testing Framework

A job-focused API automation project built with Python, pytest, and requests. It demonstrates reusable API client design, smoke and regression coverage, shared pytest fixtures, HTML reporting, and GitHub Actions CI.

GitHub Repository

Project highlights

  • Python API test automation with pytest and requests
  • Smoke and regression test suites
  • Reusable API client design
  • Shared fixture setup using conftest.py
  • HTML reporting with pytest-html
  • GitHub Actions CI integration

Covered scenarios

  • Get all products
  • Get single product
  • Validate response structure
  • Get categories and validate product category filtering
  • Create cart with POST request
  • Validate negative scenarios for missing product/category
